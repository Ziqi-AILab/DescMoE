# Historical SI results

These CSVs describe the earlier layer-placement and single-branch KAN screens.
They are separate from the corrected 16-configuration DescMoE comparison.
Values and experiment identifiers are retained as reported.

- `layer_screen_summary.csv` contains the layer-placement summaries.
- `kan_screen_detail.csv` contains dataset-level KAN screening results.
- `kan_screen_summary.csv` contains screening aggregates and assignments.

See `EXPERIMENT_PARAMETERS.md` for the layer and KAN switches, and
`configs/model_matrix.tsv` for historical model identifiers. The historical
depth and incomplete-batch protocol differ from the final evaluation.
