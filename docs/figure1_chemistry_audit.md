## Source of Assignment

Values are calculated by RDKit and passed through the same function used by the
model:

`MoleSG/pretrain/prior_moe.py`

The verification script is:

`analysis/build_verified_overview_chemistry.py`

The script contains assertions for the RDKit version, descriptor values,
region indices, and selected branch families. Figure composition reads the
resulting JSON rather than retyping the assignments.

The complete pretraining assignment audit is generated by
`analysis/audit_pretraining_descriptor_assignments.py`. It recomputes both
descriptors for all 250,000 source rows and verifies the indexed preprocessing
files. The audit found zero assignment mismatches for TPSA and MolLogP.

## Why Ibuprofen Was Chosen

Ibuprofen is absent from the ZINC 250K source rows and is used only as an
independent, familiar illustration. It produces different assignments on the
two example descriptor axes.
Its TPSA falls in region 1, which uses KAN in the locked TPSA allocation. Its
MolLogP falls in region 5, which uses MLP in the locked MolLogP allocation. One
verified structure therefore illustrates both descriptor-dependent assignment
and branch-specific function selection.

The caption must state that values are calculated for the neutral two-dimensional
input structure. MolLogP is not pH-dependent LogD, and TPSA is not a
conformer-dependent exposed polar surface.

## Prohibited Figure Content

- No Image2-generated molecular structure
- No invented bond, atom label, tautomer, stereochemistry, or charge state
- No branch index inferred by visual placement alone
- No learned router or weighted multi-branch activation
- No claim that the example represents every molecule or every descriptor axis
